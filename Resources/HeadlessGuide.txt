GUILLOTINE — OFF WITH THE HEAD

Enable Guillotine requests built-in panel power-off and turns off the
keyboard backlight while retaining the logical display. It never substitutes
screen brightness zero. Keyboard zero readback is verified; auto-brightness
is unchanged. With the lid open, built-in display enable events request off
immediately; other display changes and wake wait for events to settle. macOS
may briefly relight the panel before delivering the notification.
Duplicate layouts and periodic ticks do not request panel power. Closed or
unknown lid state and system sleep suppress event-driven reapplication.
Private APIs require revalidation after macOS updates.

Restore: Control–Option–Command–Space. Fn is optional locally; Vibepollo’s
inspected input source does not forward it. Lock leaves the mode unchanged.
When already OFF, the shortcut explicitly requests panel power-on as a rescue.
Lock-screen/Secure Input hotkey delivery still needs testing. Authentication
and lock policy remain normal. Sleep/wake restoration is optional.

Optional menu checkbox: Mute built-in speakers while headless. Off by default; changes apply
within one second while active. Uncheck or restore to return the previous mute
state. Already-muted speakers remain muted. Volume, routing, and virtual or
external audio outputs are unchanged. This silences local playback, not remote
streaming audio, and does not claim to power down audio hardware. Mute changes
are journaled for crash recovery with the other physical controls.

The root helper leases the global SleepDisabled control. THIS ALSO BLOCKS
ORDINARY AND MANUAL SLEEP while active. With this option off, sleep and
Caffeine settings remain independent. The previous experimental lid-only
control failed the physical test on this Mac and is no longer used to enable.
The new control still requires a physical closed-lid test before relying on it.

Battery sleep: enabled at 10% by default, with an editable 1–100% threshold.
Turn Sleep at a battery percentage off to leave depleted-battery behavior to
macOS. Only active headless sessions on battery use this cutoff. Controls and
owned power settings restore before requesting sleep; AC and unknown battery
readings do not trigger it. A rejected sleep request is reported.

Low Power Mode: Off, Whenever on battery, or At a battery percentage (20%
preset; editable 1–100%). Requires the approved power helper. Low Power Mode
can reduce heat while running on battery, which may help avoid thermal limits.
It may reduce performance. Only the battery profile changes, and its prior
setting restores on external power, opt-out, session end, or helper lease expiry.
Battery options apply live. Low Power Mode alone does not block system sleep.
When upgrading from build 8, Restore, Remove Helper, then Install Helper to
load the updated protocol; macOS may ask you to approve it again.

Battery use is optional, off by default. Unplugging restores unless Allow on
battery is enabled; turning it off on battery restores immediately. Replugging
never activates. Serious/critical macOS thermal pressure on battery restores
owned controls and requests system sleep. No Celsius sensor is claimed.
Other utilities’ pre-existing sleep blocks are left untouched.

Separate five-second leases protect the physical guard and privileged helper.
The helper journals the original sleep setting before changing it, restores
only its owned value, and recovers after a crash through launchd. Identical
concurrent writes cannot be attributed; avoid competing disablesleep tools.
No SIP change or private Apple entitlement is used. If the physical guard is
killed, reopen Guillotine to recover its journal. Keep pending journals until
restoration succeeds. If hardware recovery fails, restart macOS.

No virtual display, network interface, remote input, or streaming process is
changed. Preventing computer sleep and keeping capturable frames are separate.
Verify progressing frames and input after lid closure on your exact stack;
a virtual display/adapter may still be needed.

To remove: Restore, Remove Helper, disable launch at login, quit, then delete
the app. Do not remove a helper with pending sleep-setting recovery.

Supported: Apple Silicon MacBooks, macOS 13+. Intel, desktop, and external
panel power control are unavailable. Login and launch always start restored.
