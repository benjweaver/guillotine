GUILLOTINE — OFF WITH THE HEAD

Cut Screen & Keyboard switches off the built-in Apple Silicon panel and
keyboard backlight while leaving the logical display connected.

Sleep is independent. Guillotine never prevents sleep or changes sleep
settings. Caffeine and streaming hosts can continue running their own policy.
Leave the lid open or establish native clamshell operation separately.

Restore: Control–Option–Command–Space. Fn is optional in Settings; the local
Vibepollo input source does not currently forward Fn. Lock-screen and Secure
Input hotkey delivery must be tested; there is no authentication bypass.
Lock leaves the mode unchanged. Stay headless across sleep and wake is the
default; optional restore-on-sleep and restore-on-wake are in Settings.

The APIs are PRIVATE and experimental. The panel uses a power request, never
screen brightness zero. Keyboard brightness zero is checked, and its original
value is journaled for restoration. Keyboard auto-brightness is not changed.
No virtual display is created or altered. Real capture compatibility still
requires a progressing-frame/input test on the exact streaming stack.

External-power loss, app quit/crash or a five-second lease expiry restores
physical controls through a bundled nonprivileged guard. If the guard itself
is killed, reopen Guillotine to recover its journal. If recovery fails,
restart macOS. There is no root service or SIP change.

Supported: Apple Silicon MacBook, macOS 13+. Intel/desktop/external panel power
control is unavailable. Launch always starts restored. Login remains normal.
